Sobre Mí

Comprometida con la excelencia técnica, la fiabilidad del software y la automatización estratégica.

Como QA Automation Engineer, concibo el aseguramiento de calidad no como un cuello de botella al final del ciclo de vida, sino como un pilar fundamental integrado desde las etapas tempranas de desarrollo (Shift-Left Testing).

Mi experiencia se centra en diseñar e implementar frameworks de automatización modulares y escalables con herramientas modernas como Playwright, pruebas profundas de APIs REST con Postman / Newman, y la orquestación de suites completas en contenedores Docker mediante flujos de CI/CD.

Proyectos de Automatización

Casos prácticos de frameworks escalables, testing de APIs y calidad continua implementados con éxito.

E2E Framework

Playwright & TypeScript E2E Modular Framework

Framework integral de pruebas automatizadas desarrollado bajo el patrón Page Object Model (POM) con tipado estricto, diseñado para validar flujos críticos de negocio como autenticación, checkout bancario y navegación compleja.

  • Ejecución paralela multinavegador (Chromium, Firefox, WebKit).
  • Captura automática de video, snapshots y trazas en caso de fallos.
  • Generación de reportes Allure y Playwright HTML automáticos.
⚡ Reducción del 80% en tiempo de regresión vs. pruebas manuales.

API Automation

Suite de Validación de API REST con Postman & Newman

Colección completa de pruebas automatizadas para servicios backend y microservicios. Valida esquemas JSON, códigos de estado, tiempos de respuesta y flujos de tokens JWT con persistencia de variables de entorno.

  • Validación de esquemas JSON Schema (Draft-07) en cada endpoint.
  • Pruebas dinámicas data-driven utilizando archivos JSON y CSV.
  • Ejecución headless vía CLI con Newman y reportes HTML visuales.
⚡ +180 endpoints validados continuamente en menos de 45 segundos.
Postman Newman JavaScript JSON Schema
